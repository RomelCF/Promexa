# Frontend - Next.js (TypeScript)

Aplicación frontend construida con Next.js y React en TypeScript.

## Módulos y Funcionalidades
- **Autenticación y Perfiles**: Registro, login, gestión y visualización de perfil.
- **Feed Social**: Timeline de publicaciones interactivas, comentarios y reacciones.
- **Marketplace**: Catálogo de productos, filtros, creación de publicaciones de venta.
- **Chat en Tiempo Real**: Canales y mensajería instantánea mediante WebSockets.
- **Notificaciones**: Avisos en tiempo real sobre interacciones y mensajes.

## Estructura de Carpetas
- `src/app/`: Enrutamiento con App Router (grupos de rutas por módulo).
- `src/components/`: Componentes modulares y reutilizables (ui, feed, marketplace, chat).
- `src/hooks/`: Hooks personalizados de React.
- `src/lib/`: Configuración de clientes HTTP (REST) y clientes WebSocket.
- `src/types/`: Definición de tipos e interfaces TypeScript.
- `src/styles/`: Estilos globales y tokens de diseño.
